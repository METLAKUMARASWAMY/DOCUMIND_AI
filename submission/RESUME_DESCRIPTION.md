# Resume Description

## Short Project Description
Built DocuMind AI, an enterprise document intelligence platform that performs secure reviewer login, multi-document ingestion, evidence-grounded RAG, compliance and fraud detection, workflow routing, graph generation, and report export using FastAPI and React.

## Resume Bullets
- Engineered a FastAPI + React platform that analyzes contracts, invoices, purchase orders, policies, emails, and bank evidence from a synthetic enterprise dataset.
- Implemented citation-grounded retrieval with evidence chunks, document/page citations, confidence scores, and keyword fallback for low-vector matches.
- Built compliance, fraud, cross-document verification, risk scoring, workflow blocking, audit trail, and multi-agent decision modules.
- Added local Argon2id/JWT authentication, role-aware UI, protected workflow/report routes, and polished enterprise SaaS pages for submission readiness.
- Delivered production-shaped deployment assets including Docker Compose, Kubernetes manifests, GitHub Actions CI, tests, and submission documentation.

## Tech Stack
FastAPI, Pydantic, React, Vite, TypeScript, MUI, Recharts, CSS, Python, Argon2id/JWT auth, local retrieval, Docker, Kubernetes, GitHub Actions.
