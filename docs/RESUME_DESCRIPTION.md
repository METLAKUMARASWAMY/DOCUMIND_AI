# Resume Description

Built DocuMind AI, an enterprise-grade document intelligence platform using FastAPI, React, OCR/layout analysis, retrieval-augmented generation, multi-agent reasoning, compliance intelligence, fraud detection, workflow automation, and knowledge graph modeling.

## Resume Bullets

- Designed a production-shaped AI document intelligence platform for regulated industries, covering ingestion, OCR/layout analysis, classification, extraction, RAG, compliance, fraud detection, workflow, reporting, and explainability.
- Implemented a FastAPI backend with typed Pydantic contracts, modular AI service adapters, citation-grounded retrieval QA, multi-agent review, fraud/compliance engines, and report generation.
- Built a React analyst dashboard with document upload, case metrics, risk/compliance monitoring, cited search, knowledge graph exploration, and approval workflow.
- Created PostgreSQL schema design, Neo4j graph model, Docker Compose stack, Kubernetes manifests, CI workflow, security architecture, MLOps plan, and testing strategy.
- Framed research contributions around multi-document intelligence, explainable agentic reasoning, cross-document verification, and graph-enhanced fraud detection.
